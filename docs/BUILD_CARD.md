# CityMETER Fitness — first useful value

Build Card ของสัญญาการใช้งานครั้งแรกของเดโมนี้ ใช้ LDS 0.9.7 release `v0.9.7-owner.1` เอกสาร standalone `lds-0.9.7-landometer-standalone-r1` SHA-256 `d3085cbc0a50195f1cbf0c77b1d77c0d19b84364daf2948eb367348d65432d96` ไม่ใช่ใบรับรองความสอดคล้องทั้งระบบหรือผลผ่านทุกเบราว์เซอร์

## First Aha — AHA-01

**ความเข้าใจแรกที่มีประโยชน์:** สาขาฟิตเนสของแบรนด์ในชุดข้อมูลกระจุกอยู่เขต/อำเภอใด มากแค่ไหนเมื่อเทียบกับทั้งจังหวัด เขตเหล่านั้นเป็นสตูดิโอหรือยิม และนอกจังหวัดนั้นมีมากที่สุดที่ไหน ผู้ใช้เริ่มสำรวจระดับพื้นที่ได้ทันทีโดยไม่ต้องเรียนรู้ตัวกรองก่อน

ข้อความเริ่มต้น (snapshot ชีต 26 ต.ค. 2569): **“38% ของสาขาในกรุงเทพมหานครที่ระบุเขตได้ อยู่ใน 3 เขตนี้”** วัฒนา · ปทุมวัน · คลองเตย — 56 จาก 147 สาขา · อีก 39 สาขาในกรุงเทพมหานครระบุได้แค่จังหวัด · “สตูดิโอ 63% ของสาขาใน 3 เขตนี้ (35/56) · เขตอื่นของกรุงเทพมหานคร 31% (28/91)” · ข้อค้นพบรอง “นอกกรุงเทพมหานครมากที่สุด: อำเภอเมืองภูเก็ต ภูเก็ต 17 สาขา” และกติกา “นับสาขาที่ระบุเขตได้ · สตูดิโอ = เทรนนิ่ง/PT พิลาทิส คลาสบูทีค โยคะ มวย ปีนผา” ตัวเลขทั้งหมดคำนวณจากข้อมูลทุกครั้ง ไม่ใช่ค่าคงที่ใน markup

แผนที่เปิดเป็นเมือง 3 มิติ (preset `city`) ที่โฟกัส 3 เขตนั้นอัตโนมัติ (focus mode `auto`, URL ไม่มี `areas`): สี choropleth สัญลักษณ์สาขาตามรูปแบบ (เฉพาะแถวที่มีจุด) และมวลอาคารมุมโค้งเฉพาะในโฟกัส (16 tiles z14 ครบ จึงวาดได้ตั้งแต่ zoom 12) ส่วนอื่นของเมืองเป็นบริบทที่เงียบ ขอบเขตของจังหวัดที่นำโหลดก่อน จังหวัดอื่นโหลดเมื่อจำเป็น

**One useful action:** “ดูทุกพื้นที่” (ยกโฟกัส, `?areas=all`) และ “เปรียบเทียบพื้นที่” (เปิดกราฟ) เมื่อโฟกัสปิดอยู่ ปุ่มกลายเป็น “โฟกัส N เขตนี้” เมื่อเปลี่ยนตัวกรอง ข้อค้นพบ ตัวหาร และโฟกัสอัตโนมัติคำนวณใหม่ทั้งหมด

ข้อค้นพบเปิดในแผงอ่านก่อนตัวกรองใด ๆ (ตัวกรองพับอยู่ใน disclosure) บนจอแนวตั้งแคบ ข้อค้นพบและปุ่มเดียวกันแสดงในการ์ดบนแผนที่เหนือคำอธิบาย ขณะ bottom sheet ปิด ไม่มี onboarding modal ไม่มี decorative left rail หรือ bracket

## Evidence cue and calculation

แหล่ง: `data/fitness.json` (378 แถว; หน่วยเริ่มต้น 352 สาขาที่เปิดตามแหล่ง) และ `data/area-index.json` (928 เขต/อำเภอ) การคำนวณ: `summarizeAreaInsight` (`js/area-insight.js`) บนแถวที่ผ่าน `filterRows`

| เขต | รหัส | สาขา | แบรนด์ | สตูดิโอ |
|---|---|---:|---:|---:|
| วัฒนา | `1039` | 21 | 20 | 16 |
| ปทุมวัน | `1007` | 19 | 13 | 8 |
| คลองเตย | `1033` | 16 | 15 | 11 |

จังหวัดที่นำ = จังหวัดที่มีสาขาที่ระบุเขต/อำเภอได้มากที่สุด (กรุงเทพมหานคร 147 จาก 186) สัดส่วน = 56 ÷ 147 = 38% ตัวหารคือสาขาในจังหวัดนั้นที่ระบุเขตได้ ไม่ใช่ทุกสาขา และไม่ใช่ตลาดทั้งหมด บุคลิก: สตูดิโอ 35 ÷ 56 เทียบ 28 ÷ 91 ของเขตอื่นในจังหวัด (แถวที่ระบุได้แค่จังหวัดไม่อยู่ในทั้งสองฝั่ง) แสดงเมื่อทั้งสองฝั่งมีอย่างน้อย 10 สาขาและไม่ได้กรองรูปแบบ

**ไม่ตัดผ่านค่าเท่ากัน:** ถ้าเขตลำดับถัดไปมีจำนวนเท่ากับเขตสุดท้ายที่แสดง โฟกัสเหลือเฉพาะเขตที่มากกว่า (เช่น Jetts: ปทุมวัน 5 เท่านั้น เพราะหลายเขตมี 2) ถ้าทุกเขตเท่ากัน ข้อค้นพบเปลี่ยนเป็น “N เขตใน… มีสาขาเขตละ k สาขาเท่ากัน — สาขากระจาย” (เช่น Fitness First 11 เขต เขตละ 1) และข้อค้นพบนอกจังหวัดแสดงทุกพื้นที่ที่เท่ากันที่ค่าสูงสุด และไม่แสดงเมื่อค่าสูงสุดคือ 1

API ของฟังก์ชัน: `{mode, areas, areaIds, home, count, spread, homeAreaIds, homeRows, homePlaced, homeUnplaced, share, studio{focus, focusTotal, rest, restTotal, focusShare, restShare}, totalRows, placedRows, areaCount, outside{id, name, province, count, tied[]}}` และ `filterAreaRows(rows, set)` คืนแถวเดิมตามลำดับเดิม ไม่แตะพิกัด

ถ้าตัวกรองไม่มีสาขา แสดง empty state “ไม่พบสาขาตามตัวกรองนี้” พร้อม “ดูทุกสถานะ” (เมื่อสถานะอื่นมีแถว) และ “ล้างตัวกรอง” ห้ามแปลงศูนย์เป็น “ไม่มีฟิตเนสที่นี่”

## Prerequisites and safe paths — AHA-01-A

- **จำเป็นสำหรับข้อค้นพบ:** `data/fitness.json`, `data/area-index.json` โหลดและ parse ได้บน HTTP(S) เปิดเป็นไฟล์ในเครื่องจะถูกพาไปเว็บสาธารณะ (`js/launch.js`)
- **ไม่จำเป็น:** บัญชี ข้อมูลส่วนตัว ตำแหน่งผู้ใช้ สิทธิ์อุปกรณ์ การแชร์ ไลบรารีกราฟ WebGL tiles แผนที่ ขอบเขตรายจังหวัด หรืออาคาร
- แผนที่ (MapLibre จาก unpkg + tiles OpenFreeMap) และขอบเขตรายจังหวัดโหลดแยก ถ้าล้มเหลว ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้ และมีปุ่มลองโหลดแผนที่ใหม่
- ข้อมูลหลักโหลดไม่ได้ → หน้าแสดงสถานะ error พร้อม retry และลิงก์เว็บสาธารณะ ไม่แสดงตัวเลขว่าง
