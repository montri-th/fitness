# กราฟเปรียบเทียบพื้นที่

ถาดกราฟด้านล่างแผนที่ (“เปรียบเทียบพื้นที่”) มีสามมุมมอง ใช้ข้อมูลชุดเดียวกับข้อค้นพบแรกและ choropleth คือ **scopeRows** (แถวตามตัวกรองค้นหา/สถานะ/รูปแบบ/จังหวัด/แบรนด์ ก่อนเลือกพื้นที่) แท่งและช่องเป็นปุ่ม: ของเขต/อำเภอเปิดพื้นที่นั้นบนแผนที่และในแผง ของแบรนด์ตั้งตัวกรองแบรนด์และเปิดบัตรแบรนด์ กราฟวาดด้วย HTML ของเดโมเอง ไม่ใช้ไลบรารีกราฟ (`js/charts.js`, `js/chart-model.js`)

| มุมมอง (`?view=`) | คำถาม | การเข้ารหัส | ตัวชี้วัด | ขอบเขต |
|---|---|---|---|---|
| จำนวนสาขา (`count`, ค่าเริ่มต้น) | เขต/อำเภอไหนมีสาขามากที่สุด | แท่งแนวนอนเรียงลำดับ ความยาว = จำนวน สีระดับ `count` เดียวกับแผนที่ ตัวเลขอยู่นอกแท่ง ทั้งประเทศบอกจังหวัดใต้ชื่อ คำบรรยายบอกจำนวนที่ไม่อยู่ในกราฟ (ระบุได้แค่จังหวัดหรือไม่ระบุ) | จำนวน + แบรนด์ที่ต่างกัน | 20 เขต/อำเภอแรก |
| รูปแบบ (`mix`) | เขตที่มีสาขามากเป็นฟิตเนสแบบไหน | ตาราง matrix เขต × 9 รูปแบบ ทุกช่องขนาดเท่ากัน ตัวเลขในช่อง = จำนวน สีช่อง = `count` 41 ระดับตามลำดับค่าของช่องในตาราง หัวคอลัมน์มีรูปทรงของรูปแบบ | จำนวนต่อช่อง | 12 เขต/อำเภอแรกของมุมมองจำนวนสาขา |
| แบรนด์ (`brands`) | แบรนด์ใดมีสาขามากที่สุดในตัวกรองนี้ | แท่งแนวนอนเรียงลำดับ ความยาว = จำนวน สี series ของรูปแบบของแบรนด์พร้อมรูปทรง (ไม่ใช่ระดับ) | จำนวน (รวมสาขาที่ระบุได้แค่จังหวัด) | 20 แบรนด์แรกจากทั้งหมดที่พบ |

## ความหมายของการเข้ารหัส

- **ความยาวแท่ง** เทียบกับค่าสูงสุดในกราฟ ลำดับแสดงอันดับ ตัวเลขจริงอยู่ข้างแท่งเสมอ ค่าเท่ากันเรียงตามจำนวนแบรนด์แล้วตามชื่อ (เขต) หรือตามชื่อ (แบรนด์)
- **Matrix ช่องเท่ากันทุกช่อง** (`table-layout: fixed`) ขนาดช่องไม่มีความหมาย มีเพียงตัวเลขและระดับสี; ช่อง 0 คือ measured zero (ระดับ 0 + เส้นขอบศูนย์) ไม่ใช่ช่องว่าง · ตัวเลขบนสีระดับ 27–29 อยู่บนแผ่นรองสีกลาง
- **สีของแบรนด์** คือรูปแบบ (categorical) ไม่ใช่ขนาดหรือคุณภาพ รูปทรงอยู่ข้างชื่อเสมอ จึงไม่พึ่งสีอย่างเดียว

## สีและระดับ

- จำนวนต่อเขต/อำเภอ ช่อง matrix และกรอบจังหวัด: `count` (scaleVersion `4ff5c1fb…0980`) — ยอดรวม ไม่ใช่ความหนาแน่น · ใช้ครบ 41 ระดับตามลำดับค่า (`js/scales.js#buildRamp`, กติกาประจำของเจ้าของ) แท่งของกราฟจำนวนสาขาอ่าน ramp เดียวกับชั้นเขต/อำเภอบนแผนที่ (ค่าเดียวกันชุดเดียวกัน) · matrix มี ramp ของช่องในตารางเอง พร้อมแถบ 41 ระดับใต้ตาราง
- รูปแบบ: categorical `landometer-series-10-v8` ผูกด้วย id กลุ่มคงที่ พร้อมรูปทรงประจำ series (DATAVIZ-05) ไม่เปลี่ยนเมื่อกรองหรือเรียง ไม่ใช้ดาว

ทุกค่า HEX ตรง LUT 41 ค่าของ LDS 0.9.7 และเหมือนกันทั้งสองธีม (ตรวจใน `tests/scales.test.js` และ `scripts/check-lds-parity.mjs`)

## Integration contract

`renderInsightChart({elementId, view, rows: scopeRows, index, groups, theme, selectedAreaId, selectedBrand, unit, national}, onSelect)` คืน disposer; `onSelect({type: 'area', id})` หรือ `onSelect({type: 'brand', id})` ทุกการกด; `unit` มาจาก `unitWords(status)` เพื่อให้คำในกราฟตามสถานะ เปลี่ยนแท็บด้วยลูกศร/Home/End (roving tablist) URL เก็บ `view` เมื่อไม่ใช่ค่าเริ่มต้น ลิงก์ “ดูทุกแบรนด์” ในแผงเปิดถาดกราฟที่มุมมองแบรนด์

## การตรวจ

`tests/views.test.js` ตรวจว่าแท่งเรียงตามจำนวน ผลรวมช่องใน matrix เท่ากับสาขาในเขต และอันดับแบรนด์มาจากทุกแบรนด์ก่อนตัด การแสดงผลจริงสองธีมและจอแคบบันทึกใน handoff/VERIFICATION.md
