## 1. งานของผลิตภัณฑ์

ตอบ **“สาขาฟิตเนสกระจุกอยู่ตรงไหน และเป็นฟิตเนสแบบไหน”** และ **ใครอยู่เบื้องหลังแบรนด์** สำหรับทีมขยายสาขา ทีม leasing/asset และนักวิเคราะห์ เส้นทาง: ข้อค้นพบแรกแบบ 3 มิติ → เขต/อำเภอ → บัตรแบรนด์ → สาขา → แหล่งทางการ / กราฟ / ตาราง → CityMETER production

## 4. First Aha (`firstAha`)

- **บ้าน:** จังหวัดที่มีแถวที่ระบุเขต/อำเภอได้มากที่สุดในตัวกรอง
- **อันดับ:** เขต/อำเภอของบ้านเรียงตามจำนวน (แล้วจำนวนแบรนด์ แล้วชื่อ) ไม่เกิน 3 — **ไม่ตัดผ่านค่าเท่ากัน**: ถ้าเขตถัดไปเท่ากับเขตสุดท้ายที่แสดง เหลือเฉพาะเขตที่มากกว่า ไม่เหลือเลย → “กระจาย” (spread)
- **ตัวเลข:** สัดส่วน = แถวในเขตที่โฟกัส ÷ แถวของบ้านที่ระบุเขตได้ พร้อมจำนวนที่ระบุได้แค่จังหวัด
- **บุคลิก:** สัดส่วนสตูดิโอของโฟกัส เทียบส่วนอื่นของบ้าน (ตัวตั้ง/ตัวหารทั้งสองฝั่ง) แสดงเมื่อทั้งสองฝั่ง ≥ 10 แถวและไม่ได้กรองรูปแบบ
- **ข้อค้นพบรอง:** พื้นที่นอกบ้านที่มีมากที่สุด (ทุกพื้นที่ที่เท่ากัน) ซ่อนเมื่อกรองจังหวัดหรือเมื่อค่าสูงสุดคือ 1
- **กล้อง:** preset `city` fit เขตที่โฟกัส (spread → fit เขตทั้งหมดของบ้านที่มีแถว)
- **Snapshot (fixture ไม่ใช่ค่าคงที่):** BKK · วัฒนา 21 · ปทุมวัน 19 · คลองเตย 16 = 56 / 147 (38%) · ระบุได้แค่จังหวัด 39 · สตูดิโอ 35/56 เทียบ 28/91 · นอกบ้าน: เมืองภูเก็ต 17

## 5. ตัวชี้วัด ความครอบคลุม สี

- จำนวน (LDS `count`) ต่อเขต/อำเภอ จังหวัด และช่อง matrix · ไม่มีความหนาแน่น · สีครบ 41 ระดับตามลำดับค่า (`js/scales.js#buildRamp`; กติกาประจำของเจ้าของ) ต่ำสุดระดับ 0 สูงสุดระดับ 40 ค่าเท่ากันสีเดียว · คำอธิบายวาดทั้ง 41 ระดับพร้อมตัวเลขอ้างอิง (`rampLegendHTML`) · ตัวเลขบนระดับ 27–29 อยู่บนแผ่นรอง
- ทุกเขต/อำเภออยู่ในขอบเขตการค้น → ไม่มีแถว = `measured_zero` (ระดับ 0 + เส้นขอบ zero) · `no_data` คงไว้ตามสัญญาแต่ไม่ใช้ · แถวที่ไม่มีเขตนับแยก
- รูปแบบ 9 กลุ่ม ↔ LDS series ด้วย id คงที่ + รูปทรง (`js/cues.js#GROUP_SERIES`) ไม่มีดาว · สตูดิโอ/ยิม ตาม `js/model.js#FAMILY`

## 6. แผนที่

- **Focus + quiet:** รายละเอียดเฉพาะส่วนที่โฟกัส ส่วนอื่นเงียบ · โฟกัสอัตโนมัติปล่อยเมื่อไม่มีเขตโฟกัสอยู่บนจอ (`mapFocusIds`)
- **ขอบเขต:** `data/area-index.json` (ไม่มีเรขาคณิต) + `data/frames/{CODE}.json` โหลดตามต้องการ (≤ 6 จังหวัดต่อการเลื่อน)
- **กรอบจังหวัด:** count ต่ำกว่า zoom 8 เมื่อไม่ได้กรองจังหวัด · กรองจังหวัด → เห็นเขต/อำเภอของจังหวัดนั้นทุก zoom
- **สัญลักษณ์:** หนึ่งแถวที่มีจุด = หนึ่งสัญลักษณ์ · HTML pins จาก zoom 15.5 · จุดบริบทกดไม่ได้
- **อาคาร:** จุดของสาขาและตำแหน่งของศูนย์การค้า × รูปอาคาร OSM ในโฟกัส “จุดตกในอาคาร” ไม่เปลี่ยนจำนวน · อาคารเดียว = ชิ้นที่ถูกตัดที่ขอบ tile + building:part ในเส้นรอบ `hide_3d` + ชิ้นที่มีจุดเดียวกัน (`joinBuildings`) · **รายการเดียวต่ออาคาร**: สาขาที่ผูกกับศูนย์การค้าที่ตำแหน่งตกในอาคาร + สาขาที่จุดตกในอาคาร (`buildingRows`, `venueRows`) · คลิก: pin → อาคารที่ดูอยู่ (x-ray: จัดมุมใหม่) → อาคาร (ศูนย์การค้าของอาคาร / สาขาเดียว / รายการ) → จังหวัด/เขต
- **มุมมองอาคาร (เจ้าของ 29 ต.ค. 2569 19:47):** อาคารที่ดูอยู่ (`focusTarget`: อาคารของศูนย์การค้า อาคารที่เปิด อาคารของสาขาที่มีจุด) → `frameFocus` → `fitBuilding`: preset `eye` (pitch 75 · fov 24) padding ศูนย์ bearing = ผนังหลัก + 45° บนแนวทแยงที่อาคารอื่นบังน้อยที่สุด (`twoPointBearing`) ทุกจุดยอดของฐานและหลังคาเต็มกรอบว่าง (`visibleBox`) ด้านใดด้านหนึ่ง ซูมได้ถึง 21 (`BUILDING_MAX_ZOOM`) เพื่อให้อาคารเล็กหรือตึกแถวก็เต็มกรอบ · จัดกรอบด้วยรูปอาคารแบบที่วาดที่ zoom ของอาคาร (`fitPointsOf`) ไม่ใช่รูปที่วาดตอนเริ่ม · ยังไม่รู้อาคาร → กรอบ 90 ม. รอบจุด แล้วหันหาอาคารเมื่อมาถึง (≤ 2 ครั้ง ไม่ทำหลังผู้ใช้ขยับกล้อง) · ทุกทางเข้า (pin อาคาร x-ray รายการ ตาราง ค้นหา URL กลับ ดูทั้งหมด เปิด/ปิด sheet สลับ 3D) จัดกรอบใหม่ · ไม่ถูกบัง: x-ray (`js/venue-xray.js`) วาดอาคารเหนืออาคารอื่นและเหนือชื่อถนน · อาคารโฟกัสที่อยู่หน้าโปร่ง (`setScene('eye')`) · ป้ายเขตไม่ทับอาคาร · GeoJSON `maxzoom: 24` (สูงกว่ากล้องสองระดับ) · `js/maplibre-guard.js` กัน TypeError ของ MapLibre 5.6.2 เมื่อกล้องเอียงซูมออกผ่าน 13–14 บน vector source (maxzoom 14)
- **กล้อง:** `city` (ภาพรวม) · `model` (เขต สาขาไม่มีจุด) · `eye` (มุมมองอาคาร) · `plan` เมื่อปิด 3D (กรอบเดียวกันแบบแบน) · pitch ≤ 90 − fov/2 − 3
- **Breadcrumb:** ประเทศไทย › จังหวัด › เขต/อำเภอ (› ศูนย์การค้า) · `/v3/citymeter/{code}/D/{district}`
